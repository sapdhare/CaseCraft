# CaseCraft — Flutter legal practice command centre

CaseCraft is an offline-first Flutter app for iOS and Android. It is designed to be useful immediately without a cloud account or API key.

## What is ready

- Dynamic Material 3 UI with responsive phone/tablet navigation.
- Cases and other matters with client, opponent, court, judge, sections, purpose, filing/hearing dates, fees and notes.
- Hearing workflow: day-before reminder, hearing-day 18:30 update reminder, update history and next-date capture.
- Disposal workflow: Allowed / Rejected with the outcome recorded in the case history.
- Recurring daily/weekly schedule with time conflict detection and optional 30-minute reminders.
- Quick “Before giving a time” availability check.
- Search and Active / Disposed / All case filters.
- Local JSON backup + restore and explicit user-controlled sharing.
- Local-only profile / practice settings.
- No external backend configuration is required for normal use; the local repository is the app’s data backend and the device provides persistence and notification services.

## Build

Use Flutter 3.47 stable or later.

```bash
flutter pub get
flutter test
flutter run
```

For a fresh Flutter project folder without generated platform runners, run `flutter create --platforms=android,ios .` once before `flutter run`.

## Android notification setup

`flutter_local_notifications` 22.3.1 requires current Android notification permission handling and its documented scheduling setup. Keep the Android Gradle configuration generated by Flutter 3.47; then run the app and grant notification permission.

## iOS notification setup

The app requests alert, badge and sound permissions at launch. Build on a Mac with Xcode to create an iOS install/archive.
